## ⚡ Key Features

- **Interactive Slide-over Drawer**: Deep dive into full case studies with multi-section table of contents, user research insights, bespoke decision diagrams, and senior "What I'd Fix" reflections.
- **Deep-linking Hash URLs**: Share direct links with recruiters (e.g. `yourdomain.com/#index-waves`, `yourdomain.com/#ippobill`, `yourdomain.com/#setter`, `yourdomain.com/#goyab`).
- **Domain Filtering**: Instantly filter projects by *Fintech*, *Healthcare SaaS*, *Billing & Invoicing*, *E-Commerce*, and *Productivity*.
- **Reader Modal for Shorter Studies**: Instant popup viewer for secondary products without page reloading.
- **Copy-to-Clipboard Email**: One-click copy with animated feedback and direct mailto quick-message builder.
- **SEO & Social Previews**: Complete Open Graph, Twitter cards, and semantic meta tags configured.

## 🛠️ Getting Started

### Prerequisites
- Node.js (v18 or newer)
- npm or pnpm or yarn

### 1. Install dependencies
```bash
npm install
```

### 2. Run local development server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Build for production
```bash
npm run build
```
The optimized production bundle is emitted to the `dist/` directory.

### 4. Preview production build locally
```bash
npm run preview
```

---

## 🌐 1-Click Deployment

### Deploy to Vercel
```bash
npm i -g vercel
vercel
```

### Deploy to Netlify
Drag and drop the `dist/` folder into Netlify Drop, or run:
```bash
npm i -g netlify-cli
netlify deploy --prod --dir=dist
```

### Deploy to GitHub Pages
Add `"base": "/repo-name/"` to `vite.config.js` and push the `dist/` directory to your `gh-pages` branch.
